What this is

This atlas maps the structural fault lines of the male fruit fly central nervous system: how sensory signals can reach motor neurons, where the wiring is thinnest, and what breaks when parts are removed. It is built from the MaleCNS v1.0 connectome (Berg et al., Cell 2026) and the exact outputs of our analysis pipeline. Every number on this site is generated from the same results files as the paper, so the two can never disagree.

Two synapse thresholds are shown throughout. An edge between two neurons is kept only if it carries at least that many synapses: 5, the common weak-connection cutoff, and 11, the noise threshold used in the MaleCNS paper itself.

How to read this atlas

Min-cut atlas

The exact minimum sets of edges whose removal disconnects all sensory-to-motor routes. These are mathematical facts about the graph, computed exactly, not statistical claims. Start here for the hard structural findings.

Lesion explorer

What happens when nodes or edges are removed at random versus removed by targeting rules (high out-degree, approximate betweenness, cut membership, edge weight). These comparisons are exploratory. None of the targeted-versus-random tests survived correction for multiple comparisons, so treat every pattern on that page as a lead for future work, not a finding.
