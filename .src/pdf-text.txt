The gap this fills
The final Cell article already includes sensorimotor max-flow analysis [1], so basic flow analysis is not a novel
contribution. Two 2026 arXiv preprints add relevant prior art: FlyGM reports a connectome-shaped controller
for simulated fly locomotion [5], while FLYNN reports robustness experiments in fly-topology robot navigation
[6]. The distinct lesion-response and structural-resilience benchmark remains a candidate contribution until a
formal literature review establishes novelty.
Novelty gate: Run a dated search across peer-reviewed databases and preprint servers before coding. If an existing
study already reports the same MaleCNS whole-CNS lesion benchmark, narrow the study to a modality, such as visionto-flight control, or to verified dimorphic versus shared circuitry.

Initial pathway panels
Start only with pathways whose source and target annotations are clear. The visual panel may use Janelia's
official R1-R6 to DNg13 visual-to-motor example as a documented case [4]. It is an anatomical pathway
example, not evidence that the static connectome reproduces dynamic behavior. Add olfactory, gustatory,
mechanosensory, and proprioceptive panels only after an annotation audit confirms usable coverage.
Scope boundary: The graph represents structural connectivity. Synapse count is a weight proxy, not a measured firing
rate. Any dynamic model belongs in a later paper after physiological assumptions can be justified.

Graph construction
Represent every neuron as a node and each documented directed synaptic connection as an edge. Use
summed synapse counts as the base edge weight. Do not add electrical-coupling data unless a separate
verified source is available, and never force it into the same directed model. Record each filter in a machinereadable manifest.

Threshold plan
Run the primary analysis at a prespecified minimum synapse count chosen after the distribution audit.
Repeat it across at least three thresholds, including the unthresholded graph, to show whether conclusions
depend on weak edges.

Pathway definitions
Sources: modality-specific sensory populations with clear annotations.
Targets: descending neurons for brain-to-cord analysis and motor neurons for end-to-end analysis.
Allowed paths: directed paths within a biologically reasonable hop limit, reported as a sensitivity
parameter rather than a hidden rule.
Compartments: full CNS, brain-to-descending, and descending-to-motor segments.

Null models
Degree-preserving rewires test whether
resilience follows simply from each neuron's
number of inputs and outputs.

Region-constrained rewires preserve coarse
anatomy while breaking exact neuron-toneuron structure.

Reproducibility requirement: Fix random seeds, save every graph transform, publish environment
files, and make all reported figures regenerable from one command.

Statistical plan
Report median differences, standardized effect sizes, and 95 percent bootstrap confidence intervals.
Use permutation tests for observed-versus-null comparisons.
Control the false discovery rate when testing many cell types or regions.
Separate confirmatory tests for H1-H3 from exploratory analysis for H4.
Publish negative and null findings rather than selecting only visually dramatic circuits.
Compute plan: Begin with sparse graph operations and pathway panels. Full all-pairs calculations are unnecessary.
Scale only after profiling memory, runtime, and the number of reachable source-target pairs.

Section-by-section writing plan
1. Introduction: Explain why a complete brain-and-cord graph changes the resilience question and state the

Scale

Novelty
overlap

Recent work is appearing quickly.

Freeze the final question only after a dated literature
matrix and advisor review.

Go or no-go checkpoints
GO IF: The official release provides stable IDs, synapse edges, and enough functional labels to define at
least two pathways.
GO IF: The literature screen finds no study with the same MaleCNS whole-CNS robustness benchmark.
NARROW IF: Labels support only one modality. Publish a deep visual sensorimotor study instead of a
broad atlas.
STOP IF: Results change direction under reasonable thresholds or null models and cannot be explained
transparently.

Best next action: Complete the novelty matrix and data dictionary first. Those two documents
determine whether this becomes a credible paper or just an attractive demo.
